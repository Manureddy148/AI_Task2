# The Audit — AI Team Intern Assignment 2026

A previous intern benchmarked our tokenizer (`fertility.py`) and our serving stack
(`bench/`), wrote `REPORT_v0.md`, and left. Leadership is about to make routing and
capacity decisions based on that report. **This repo is the audit of that report** —
every claimed flaw ships with the exact command, before/after numbers, and one
sentence on why the delta proves the claim.

## The deliverable at a glance

```text
submission/
  REPORT_v1.md       the corrected report (deck-ready, with figures)
  verify.py          numbers-under-test: re-derives and asserts all 50 headline figures
  NOTEBOOK.md        chronological lab notebook: hypothesis → experiment → result, dead ends included
  AI_USAGE.md        honest account of where AI helped and where it misled
  partA/             tokenizer audit: 7-language corpus, bug isolation, 5-tokenizer corrected analysis, memo
  partB/             capacity reconciliation: KV arithmetic, per-row log replay, roofline, answers
  partC/memo.md      decision memo: casual-tone paths (SFT vs rewriter vs prompting)
```

## Reproducing everything

All numbers in the submission are regenerated by scripts in `submission/partA/` and
`submission/partB/`. See [submission/README.md](submission/README.md) for the exact
commands (Python 3.14, `pip install -r submission/requirements.txt`, one script per
experiment — no notebook state, no manual steps).

## Operating principle

> A claimed flaw without measured evidence scores negative points.

So this audit makes few claims and measures all of them. Anything that looked
suspicious but measured out clean is reported as *cleared*, with the experiment
that cleared it.
